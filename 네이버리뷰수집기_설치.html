1수집기 설치 (최초 1회)

아래 초록색 버튼을 브라우저 북마크바로 드래그하세요. 끝입니다.

📥 리뷰 수집기
북마크바가 안 보이면 Ctrl+Shift+B (Mac: ⌘+Shift+B)로 켤 수 있어요
드래그 설치가 안 될 때 (콘솔 실행 방식)

리뷰 페이지에서 F12 → Console 탭을 열고 아래 코드를 붙여넣은 뒤 Enter를 누르면 동일하게 작동합니다.

2리뷰 페이지 열기

중요: PC용 네이버 지도(map.naver.com)의 왼쪽 패널에서는 작동하지 않습니다. 모바일 플레이스 페이지를 PC 브라우저에서 직접 열어야 해요.

  1. PC 네이버 지도(map.naver.com)에서 업체를 검색해 클릭
  2. 브라우저 주소창의 URL 전체를 복사 (naver.me 공유 링크 아님)
  3. 아래 변환기에 붙여넣으면 리뷰 페이지 링크가 만들어집니다

열린 페이지 주소가 m.place.naver.com/…/review/visitor 형태이고 리뷰 목록이 보이면 준비 완료입니다. 첫 번째 링크에서 "페이지를 찾을 수 없음"이 뜨면 두 번째 링크로 여세요.

3수집 실행

  1. 리뷰 탭이 열린 상태에서 북마크바의 📥 리뷰 수집기 클릭
  2. 화면 우하단에 진행 카운터가 뜨고, 자동으로 스크롤하며 '더보기'를 끝까지 누릅니다
  3. 완료되면 업체명_reviews_날짜.json 파일이 자동 다운로드됩니다
  4. 리뷰 1,000개 기준 약 2~3분 소요 · 도중에 멈추고 싶으면 '지금까지 수집분 저장' 클릭
수집 중 주의: 탭을 최소화해도 되지만 닫지는 마세요. 같은 창에서 다른 페이지로 이동하면 수집이 중단됩니다.

4분석 의뢰

다운로드된 JSON 파일을 Claude에게 업로드하고 이렇게 요청하세요:

"이 리뷰 데이터 분석해줘 — 불만 테마 분류, 사장님 답글률과 톤 진단, 전략 시사점 뽑아줘"

JSON에는 각 리뷰의 원문(rawText)이 통째로 보존되어 있어서, 자동 분류가 놓친 뉘앙스도 분석 단계에서 잡아냅니다.

⚠️ 문제 해결

목록을 못 찾음리뷰 탭이 열려 있는지, 주소가 m.place.naver.com인지 확인. 페이지 새로고침 후 재시도.
수집이 중간에 멈춤네트워크가 느리면 로딩 전에 종료 판정될 수 있어요. '지금까지 수집분 저장'으로 일단 받고, 새로고침 후 재실행하면 처음부터 다시 수집됩니다.
답글 수가 이상함답글 감지는 추정값입니다. 본문에 '사장님'이라는 단어가 들어간 리뷰가 오탐될 수 있는데, 분석 단계(Claude)에서 원문 기준으로 걸러냅니다.
주황색 경고가 뜸수집기가 화면 구조 변화를 스스로 감지한 것입니다. 파일은 저장되니, 그 JSON을 Claude에게 가져오면 무엇이 어떻게 바뀌었는지 진단 정보를 보고 바로 수정할 수 있습니다.
어느 날부터 작동 안 함네이버가 화면 구조를 바꾼 경우입니다. 이 파일과 함께 "수집기가 안 된다"고 Claude에게 가져오면 수정해 드립니다.
