구글맵 리뷰 수집기 외국인 반응 분석용 · 구글 지도 리뷰 전체를 JSON 파일로 저장합니다

1수집기 설치 (최초 1회)

아래 초록색 버튼을 브라우저 북마크바로 드래그하세요. 끝입니다.

📥 구글 리뷰 수집기
북마크바가 안 보이면 Ctrl+Shift+B (Mac: ⌘+Shift+B)로 켤 수 있어요
드래그 설치가 안 될 때 (콘솔 실행 방식)

리뷰 페이지에서 F12 → Console 탭을 열고 아래 코드를 붙여넣은 뒤 Enter를 누르면 동일하게 작동합니다.

2리뷰 화면 열기

  1. PC 크롬에서 google.com/maps 접속 후 업체 검색
  2. 업체 정보 패널에서 리뷰 탭 클릭 (리뷰 목록이 왼쪽 패널에 보여야 함)
  3. 권장: 정렬 버튼을 눌러 '최신순'으로 변경 — 기본값(관련성순)은 오래된 리뷰가 섞여 최신 동향 파악에 불리합니다
번역 참고: 외국어 리뷰를 구글이 자동 번역해 보여주는 경우 번역문이 수집됩니다. 수집 데이터에 언어 추정(langGuess)과 번역 여부(wasTranslated)가 함께 기록되니 분석 시 구분됩니다.

3수집 실행

  1. 리뷰 탭이 열린 상태에서 북마크바의 📥 구글 리뷰 수집기 클릭
  2. 화면 우하단에 진행 카운터가 뜨고, 리뷰 패널을 자동 스크롤하며 끝까지 로드합니다
  3. 완료되면 업체명_google_reviews_날짜.json 파일이 자동 다운로드됩니다
  4. 리뷰 350개 기준 약 1~2분 소요 · 도중에 멈추고 싶으면 '지금까지 수집분 저장' 클릭
수집 중 주의: 탭을 최소화해도 되지만 닫지는 마세요. 같은 창에서 다른 페이지로 이동하면 수집이 중단됩니다.

4분석 의뢰

다운로드된 JSON 파일을 Claude에게 업로드하고 이렇게 요청하세요:

"구글 리뷰 데이터 분석해줘 — 외국인/내국인 반응 비교, 언어별 칭찬·불만 테마, 소유자 응답률 진단해줘"

JSON에는 각 리뷰의 원문(rawText)이 통째로 보존되어 있어서, 자동 분류가 놓친 뉘앙스도 분석 단계에서 잡아냅니다.

⚠️ 문제 해결

목록을 못 찾음구글 지도에서 업체를 선택하고 리뷰 탭을 열었는지 확인. 리뷰 목록이 화면에 보여야 시작됩니다.
수집이 중간에 멈춤네트워크가 느리면 로딩 전에 종료 판정될 수 있어요. '지금까지 수집분 저장'으로 일단 받고, 새로고침 후 재실행하면 처음부터 다시 수집됩니다.
답글 수가 이상함답글 감지는 추정값입니다. '(소유자) 응답' 표기를 기준으로 감지하므로 비교적 정확하지만, 표기 변경 시 오차가 생길 수 있는데, 분석 단계(Claude)에서 원문 기준으로 걸러냅니다.
주황색 경고가 뜸수집기가 화면 구조 변화를 스스로 감지한 것입니다. 파일은 저장되니, 그 JSON을 Claude에게 가져오면 무엇이 어떻게 바뀌었는지 진단 정보를 보고 바로 수정할 수 있습니다.
어느 날부터 작동 안 함구글이 화면 구조를 바꾼 경우입니다. 이 파일과 함께 "수집기가 안 된다"고 Claude에게 가져오면 수정해 드립니다.
