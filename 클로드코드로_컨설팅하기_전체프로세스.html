Part 0 · Toolset · 컨설팅 시작 전에 딱 한 번

터미널 준비 — 도구부터 손에 익히기

이 파트는 컴퓨터에서 "글자만 있는 까만 창"을 한 번도 열어본 적 없는 분을 기준으로 썼습니다. 아래 Stage 00~04가 컨설팅 절차라면, 여기는 그 절차를 돌리는 도구를 세팅하는 곳입니다. 설치는 약 15분, 찬찬히 읽으면 약 30분. 준비물은 Windows PC와 클로드 구독 계정뿐입니다.

시작 전에, 이 6개 낱말만 알고 갑니다

아래 여섯 단어는 이 문서 전체에서 계속 나옵니다. 지금 완벽히 외울 필요는 없고, 뒤에서 막힐 때 여기로 돌아와 다시 보면 됩니다.

  • 터미널 마우스로 아이콘을 클릭하는 대신, 글자를 입력해서 컴퓨터에게 일을 시키는 화면입니다. 메뉴도 버튼도 없이 글자만 있어서 낯설지만, 사실은 "컴퓨터와 글로 대화하는 채팅창"이라고 생각하면 편합니다.
  • 명령어 터미널 안에서 컴퓨터가 알아듣는, 정해진 형태의 문장입니다. 띄어쓰기 하나, 철자 하나까지 원래 정해진 그대로 입력해야 컴퓨터가 알아듣습니다. 마음대로 줄이거나 바꿔 쓰면 안 됩니다.
  • Enter 명령어를 다 입력한 뒤 누르는 키입니다. "이제 이 말대로 진짜 실행해!"라고 컴퓨터에 보내는 신호입니다. 타이핑만 하고 Enter를 안 누르면 아무 일도 일어나지 않습니다.
  • 설치 인터넷에서 프로그램 파일을 내려받아 내 컴퓨터 안에 넣어두는 것입니다. 한 번만 설치해두면, 그다음부터는 인터넷 없이도 그 프로그램을 계속 쓸 수 있습니다.
  • 폴더 · 경로 폴더는 파일을 모아두는 서랍입니다. 경로는 그 서랍이 컴퓨터 안 어디에 있는지 알려주는 주소라고 보면 됩니다. Stage 00에서 클라이언트마다 이 서랍 구조를 똑같이 맞춥니다.
  • 확장자 파일 이름 끝에 점(.)과 함께 붙어서 파일의 종류를 알려주는 표시입니다. 사진은 .jpg, 워드 문서는 .docx처럼요. 곧 만들 메모 파일은 .md로 끝납니다.

설치 5단계 (Windows 기준)

처음 한 번만 설치하면 그다음부터는 계속 재사용합니다. 하나씩 끝내고 다음으로 넘어가세요 — 건너뛰면 뒤에서 반드시 막힙니다.

  1. 1

    Node.js 설치하기

    클로드 코드는 원래 외국(Anthropic이라는 회사)에서 만든 프로그램이라, 우리 Windows 컴퓨터가 이 프로그램을 이해하고 실행할 수 있게 도와주는 "통역 프로그램"이 하나 더 필요합니다. 그 통역 프로그램의 이름이 Node.js입니다. 클로드 코드를 설치하기 전에 이것부터 컴퓨터에 넣어둬야 합니다.

    평소 인터넷을 할 때 쓰는 브라우저(크롬, 엣지 등)를 열고 주소창에 nodejs.org를 입력한 뒤 Enter를 누르세요. 사이트가 열리면 초록색 버튼이 두 개 보입니다. 이 중 왼쪽에 있는, "LTS"라고 적힌 버튼을 클릭하세요. (오른쪽 "Current" 버튼은 누르지 마세요 — 우리에게 필요 없는 최신 실험판입니다.)

    다운로드된 파일(화면 아래쪽이나 브라우저 오른쪽 위에 나타납니다. 이름이 node-v22.x.x-x64.msi 처럼 생겼습니다)을 마우스로 더블클릭해서 여세요. 설치 화면이 뜨면 다른 건 건드리지 말고 "Next"(다음) 버튼만 계속 눌러주면 됩니다. 마지막에 "Finish"(완료) 버튼이 나오면 눌러서 설치를 마칩니다. 잘 설치됐는지는 3번 단계에서 확인하니, 지금은 설치만 끝내고 넘어가면 됩니다.

  2. 2

    PowerShell(터미널) 창 열기

    PowerShell은 Windows에 원래 들어있는 터미널 프로그램의 이름입니다. 앞서 말한 "글자로 대화하는 창"이 바로 이것입니다.

    키보드 맨 아래 줄, 왼쪽에서 세 번째 즈음에 있는 창문 모양 로고 키(윈도우 키)를 누르세요. 화면 왼쪽 아래에 검색창이 뜹니다. 거기에 영어로 PowerShell이라고 입력하세요. (한글이 입력된다면 키보드의 한/영 키를 한 번 눌러 영문 모드로 바꾼 뒤 다시 입력하세요.)

    검색 결과 맨 위에 짙은 파란색 아이콘과 함께 "Windows PowerShell"이 나타나면, 그 위에서 Enter를 누르거나 마우스로 클릭하세요. 확인 짙은 파란색 또는 검은색 배경의 네모난 창이 화면에 뜨고, 안에 흰 글씨가 몇 줄 적혀 있고, 맨 아래 줄 끝에 깜빡이는 세로 막대(커서)가 보이면 성공입니다. 이 창을 이제부터 계속 쓸 거예요.

  3. 3

    Node.js가 잘 설치됐는지 확인

    방금 연 창에 마우스로 아무것도 클릭하지 말고, 키보드로 바로 아래 글자를 그대로 입력하세요. (아래 박스 오른쪽 위의 "복사" 버튼을 눌러서 붙여넣어도 됩니다 — 터미널 창 안에서는 마우스 오른쪽 버튼 클릭이 붙여넣기인 경우가 많습니다.)

    PowerShell
    PS> node -v
v22.14.0

    성공 입력 후 Enter를 누르면 바로 아래 줄에 v22.14.0처럼 v로 시작하고 점(.)으로 나뉜 숫자가 나타나면 정상입니다. 주의 대신 'node'은(는) 내부 또는 외부 명령... 인식되지 않습니다 같은 문구가 뜨면 Node.js가 제대로 설치되지 않은 것입니다 — 아래 트러블슈팅을 확인하세요.

  4. 4

    클로드 코드 설치

    아래 명령어를 그대로 입력하고 Enter를 누르세요.

    PowerShell
    PS> npm install -g @anthropic-ai/claude-code

    이 한 줄의 뜻을 풀면 이렇습니다 — npm은 Node.js를 설치할 때 같이 딸려오는 "설치 담당 도우미"이고, install은 "설치해줘", -g는 "내 컴퓨터 어디서든 쓸 수 있게", @anthropic-ai/claude-code는 우리가 설치하려는 프로그램의 정확한 이름입니다.

    Enter를 누르면 화면에 회색·흰색 글자가 줄줄이 올라오기 시작합니다. 중간에 잠깐 화면이 멈춘 것처럼 조용해 보이는 순간이 있어도 정상이니 그냥 기다리세요. 보통 1~2분 정도 걸립니다. 완료 신호 글자가 더 이상 올라오지 않고, 맨 아래에 PS C:\Users\내이름> 같은 줄과 깜빡이는 커서가 다시 나타나면 설치가 끝난 것입니다. 별도로 "성공했습니다" 같은 메시지는 안 뜨는 경우가 많으니, 커서가 돌아왔는지로 판단하면 됩니다.

  5. 5

    실행하고 로그인하기

    설치가 끝나면 아래 명령어로 클로드 코드를 실행합니다.

    PowerShell
    PS> claude

    몇 초 뒤 평소 쓰는 인터넷 브라우저가 자동으로 새 창(또는 새 탭)으로 열리면서 클로드 로그인 화면이 나타납니다. 평소 claude.ai에 접속할 때 쓰는 이메일과 비밀번호로 로그인하세요.

    로그인이 끝나면 브라우저 화면에 "연결되었습니다"와 비슷한 완료 문구가 뜹니다. 이 브라우저 창(탭)은 이제 볼 일이 없으니 닫아도 되고, 그냥 둬도 상관없습니다. 화면 아래쪽 작업표시줄에서 아까 그 파란색·검은색 터미널 창을 다시 클릭해서 돌아오세요.

    성공 터미널 창 안에 색이 들어간 환영 문구나 안내 메뉴가 나타나면 로그인이 잘 된 것입니다. 테마 선택 같은 질문이 몇 개 나올 수 있는데, 잘 모르겠으면 기본값 그대로 Enter를 눌러 넘어가도 괜찮습니다. 맨 아래에 글자를 입력할 수 있는 빈 칸이 보이면 준비 완료입니다 — 이제부터 여기에 원하는 걸 문장으로 입력하면 됩니다.

이게 안 될 때 — 자주 만나는 문제 3가지

1) "npm은(는) 내부 또는 외부 명령... 인식할 수 없습니다"라는 문구가 뜰 때 — Node.js를 설치한 뒤 PowerShell 창을 새로 열지 않아서 그렇습니다. 지금 열려 있는 창 오른쪽 위의 X 버튼을 눌러 완전히 닫고, 2번 단계부터 다시 새로 열어서 시도하세요.

2) 그래도 계속 같은 문구가 뜰 때 — 컴퓨터를 한 번 재부팅한 뒤, 이번엔 PowerShell 검색 결과 위에서 마우스 오른쪽 버튼을 클릭하고 "관리자 권한으로 실행"을 선택해서 다시 시도해보세요.

3) claude 입력 후 브라우저가 저절로 열리지 않을 때 — 터미널 화면에 https://로 시작하는 긴 주소가 함께 표시됩니다. 그 주소를 마우스로 드래그해서 선택한 뒤 오른쪽 버튼으로 복사하고, 직접 브라우저를 열어 주소창에 붙여넣어 접속하세요.

자주 쓰는 명령어 6개

외울 필요 없이, 필요할 때마다 여기서 그대로 옮겨 적으면 됩니다. 아래 표의 딱 6개만 알아도 실무에서 막힐 일이 거의 없습니다. 띄어쓰기 하나까지 표시된 그대로 입력해야 컴퓨터가 알아듣습니다.

화면에 보이는 PS> 같은 기호는 직접 입력하는 게 아닙니다. 터미널 화면 왼쪽에 컴퓨터가 저절로 띄워주는 표시일 뿐이니, 그 뒤에 나오는 명령어 글자만 입력하세요.

그리고 Enter를 반드시 눌러야 실행됩니다 — 다 타이핑해놓고 Enter를 안 누르면 화면은 그냥 그대로 멈춰 있습니다.

명령어하는 일예시
cd 폴더명 지금 있는 폴더에서 그 이름의 폴더 "안으로" 들어갑니다. 방을 걸어 들어가는 것과 같습니다. cd 다물도
cd .. 지금 있는 폴더에서 "한 칸 바깥"(상위 폴더)으로 나갑니다. cd ..
dir 지금 폴더 안에 어떤 파일·폴더가 있는지 목록으로 보여줍니다. 방에 들어가서 둘러보는 것과 같습니다. dir
mkdir 폴더명 새 폴더(빈 서랍)를 만듭니다. mkdir _assets
claude 지금 있는 폴더 안에서 클로드 코드를 켭니다. claude
Ctrl + C 지금 하던 작업을 멈추거나 클로드 코드를 끕니다. Ctrl 키와 C 키를 동시에 누르는 것으로, 마우스로 무언가 복사한다는 뜻이 아니라 "중단"이라는 뜻입니다. (키보드 단축키)

습관 하나만 들이세요. 클라이언트마다 작업 폴더를 하나 정해두고, 항상 cd 폴더명으로 그 안에 들어간 다음 claude를 실행합니다. 이 습관만 있으면 파일이 여기저기 흩어지지 않고, Stage 00의 폴더 구조가 그대로 유지됩니다.

터미널 안에 긴 글자를 붙여넣을 때는 보통 Ctrl+V로 됩니다. 안 되면 마우스 오른쪽 버튼을 한 번 눌러보세요 — 터미널에서는 오른쪽 클릭이 붙여넣기인 경우가 많습니다.

CLAUDE.md — 폴더에 놓아두는 업무 지시서

CLAUDE.md는 클로드 코드에게 "너는 이런 역할이고, 이런 규칙으로 일해줘"라고 미리 일러두는 메모 파일입니다. 이름 끝의 .md가 앞에서 배운 확장자입니다. 작업 폴더 안에 이 이름 그대로 저장해두면, 그 폴더에서 claude를 실행할 때마다 자동으로 읽고 시작합니다. 매번 "너는 활동기록지 담당이야"라고 새로 설명할 필요가 없어지는 겁니다.

CLAUDE.md에는 보통 네 가지를 적습니다 — 역할(무슨 일을 하는 사람인지), 구조(문서 항목이나 폴더 구성), 문체 규칙(말투와 금지사항), 출력 형식(파일 형식과 파일명 규칙). 클라이언트가 바뀌면 이 파일만 갈아끼우면 됩니다.

실제로 만들어보는 건 Stage 03에서 합니다. 메모장으로 CLAUDE.md를 만들어 저장하고, 프롬프트를 넣고, 결과 파일까지 확인하는 전 과정을 Stage 03 · 정부제출용 활동기록지 항목에 실습으로 넣어뒀습니다. 그 실습이 이 문서에서 가장 중요한 한 덩어리입니다.
